# Changelog

## [1.0.0] - 2026-03-15

### Added

- Initial production-ready digital banking platform.
- Multi-tenant SaaS architecture with RLS.
- Retail banking suite (Dashboard, Transfers, Bills, Check Deposit).
- Finance control room with Carbon tracking and AI health scores.
- Admin SaaS & Setup Bank consoles.
- Full Supabase schema with 20+ entities.
- Playwright E2E suite and verification script.

### Changed

- Migrated from simple MVP stubs to full functional workspaces.
- Upgraded branding system to use dynamic theme resolution.

### Fixed

- Resolved all cross-tenant data leakage risks via RLS policies.
- Fixed hydration and suspense issues in multi-tenant routing.
