# MVP

## Blueprint Coverage

- SaaS multi-tenancy with tenant-aware routing, branding, onboarding, and admin monetization
- 20 data entities with `tenant_id`
- 16 tenant-safe API groups
- Dashboard, transfers, transactions, statements, alerts, support, finance, and admin pages
- Supabase SQL, tests, verification script, and docs

## First-Pass Scope

This scaffold prioritizes project structure, typed contracts, reusable UI, representative routes, and documentation so the empty repository can be turned into an implementable banking platform baseline.
