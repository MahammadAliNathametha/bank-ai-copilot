# Agent Browser Skill

Use this skill to test web applications using browser automation.

---

# Purpose

Verify that UI flows work correctly.

Examples:

- login flow
- dashboard navigation
- transaction pages
- form submissions

---

# Testing Steps

1. Open browser
2. Navigate to the application
3. Run user flows
4. Validate UI elements
5. Capture errors
